# Edytor plansz WORLDS KONTRA

Adres po wdrożeniu: `https://lol-kontra.axword.pl/admin/dailies/daily/builder/`.
Zaloguj się kontem administratora. W menu Dailies wybierz „Przygotuj planszę” albo „Edytor reguł” przy istniejącym dniu.

1. Wybierz datę i po jednym lub dwóch warunkach dla pięciu ról. Listę można filtrować nazwą bohatera, krajem lub osiągnięciem.
2. Licznik pokazuje zawodników spełniających **wszystkie warunki danego pola**. Rozwiń „Pasujący zawodnicy”, by zobaczyć nicki.
3. Standardowe plansze wymagają minimum 10 odpowiedzi na każde pole. Uzupełnienie autora oznacza planszę gościnną, dla której dopuszczamy mniej odpowiedzi.
4. „Zapisz szkic” zachowuje poprawną planszę bez udostępniania jej graczom. „Opublikuj planszę” udostępnia ją od wybranej daty w strefie Europe/Warsaw.

Opublikowaną planszę można zmienić tylko do pierwszego rozpoczętego meczu. Archiwalne i rozpoczęte gry mają zablokowany zapis reguł. Każda plansza musi dać się rozwiązać pięcioma różnymi zawodnikami.

Konto wymaga uprawnień dodawania i zmiany Daily, DailySlot i DailySlotCondition albo statusu superuser. Podgląd odpowiedzi wymaga logowania i nie jest dostępny publicznie.

# Ranking

Domyślny ranking ważony: `(suma punktów gracza + 5 × średnia wszystkich ukończonych oficjalnych gier) / (liczba gier gracza + 5)`.
Niższy wynik jest lepszy. Gracz bez ukończonych gier nie otrzymuje miejsca ani sztucznego wyniku 0.
Można przełączyć sortowanie na zwykłą średnią i przechodzić po wszystkich stronach rankingu.

# Profile i domeny

Stara domena odczytuje wyłącznie istniejący lokalny dostęp do profilu, przenosi go formularzem HTTPS na nową domenę, weryfikuje w bazie i dopiero potem przekierowuje.
Jeżeli na nowej domenie istnieje już inny profil, gracz wybiera, którego używać. Dostęp do bieżącego profilu można wcześniej zapisać do pliku.
W profilu na nowej stronie dostępny jest link „Przenieś profil ze starej domeny”, również dla telefonu.
Nigdy nie udostępniaj pliku dostępu do profilu ani jego zawartości.
